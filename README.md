# 🎓 Student Performance Prediction

A beginner-to-intermediate machine learning project that analyzes student data and predicts academic performance using Python and Scikit-learn.

Built as part of my **B.Tech in Artificial Intelligence & Data Science (3rd Semester)** to practice the complete data science workflow: cleaning data, exploring it visually, training models, and judging them with the right metrics.

---

## 🎯 Problem Statement

Can we predict how a student will perform based on habits and background such as study time, attendance, and past grades?

I solved it in two ways:

| Task | Goal | Models used |
|------|------|-------------|
| **Classification** | Predict whether a student will **Pass or Fail** (pass mark = 50) | Logistic Regression, Decision Tree, Random Forest |
| **Regression** | Predict the exact **final score** (0–100) | Linear Regression, Random Forest Regressor |

## 🛠️ Tech Stack

`Python` · `Pandas` · `NumPy` · `Scikit-learn` · `Matplotlib` · `Seaborn`

## ✨ Features

- **Data cleaning**: removes duplicate rows, fills missing values (median for numbers, mode for categories)
- **Exploratory data analysis**: score distribution, correlation heatmap, scatter plots, boxplots
- **Preprocessing pipeline**: scaling + one-hot encoding using `ColumnTransformer` and `Pipeline`
- **Model training and comparison** with an 80/20 train-test split (stratified for classification)
- **Evaluation metrics**: accuracy, precision, recall, F1-score, confusion matrix, 5-fold cross-validation, MAE, RMSE, R²
- **Feature importance** to see which habits matter most

## 📊 Dataset

The dataset (`data/students.csv`) is **synthetic**, generated by `generate_data.py` (1,000 students, 10 features). I generated it so the project is fully reproducible, and I deliberately added missing values and duplicate rows so the cleaning step is meaningful.

| Feature | Type |
|---------|------|
| `gender`, `internet_access`, `parental_support`, `extracurricular` | Categorical |
| `study_hours_per_week`, `attendance_pct`, `previous_grade`, `assignments_completed_pct`, `sleep_hours`, `absences` | Numerical |
| `final_score` | Target (regression), converted to Pass/Fail for classification |

> ⚠️ Because the data is synthetic, the results show that the pipeline works, **not** real-world findings about students. See *Using your own data* below to run it on a real dataset.

## 📈 Results

**Classification (Pass / Fail)**

| Model | Accuracy | Precision | Recall | F1 | 5-Fold CV Acc |
|-------|----------|-----------|--------|-----|---------------|
| Logistic Regression | 0.86 | 0.899 | 0.922 | 0.910 | 0.901 |
| Decision Tree | 0.83 | 0.885 | 0.896 | 0.890 | 0.826 |
| Random Forest | 0.86 | 0.894 | 0.929 | 0.911 | 0.866 |

**Regression (final score)**

| Model | MAE | RMSE | R² |
|-------|-----|------|----|
| Linear Regression | 3.79 | 4.60 | 0.749 |
| Random Forest | 4.39 | 5.40 | 0.655 |

**Top factors for Pass/Fail (Random Forest):** study hours per week, previous grade, assignments completed, attendance, sleep hours.

## 💡 Key Learnings

- **Accuracy alone can mislead.** My first version had a ~97% pass rate, so almost any model scored ~97% accuracy. I rebalanced the classes and focused on precision, recall and F1 instead.
- **A more complex model isn't always better.** Linear Regression beat Random Forest on this data, because the underlying relationships are mostly linear.
- **Pipelines matter.** Putting preprocessing inside a `Pipeline` keeps test data from leaking into training (for example when scaling).
- Study habits and past performance mattered more than background factors.

## 🚀 How to Run

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/student-performance-prediction.git
cd student-performance-prediction

# 2. (Optional) create a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Generate the dataset and run the project
python generate_data.py
python student_performance.py
```

Charts are saved to `images/` and metrics to `classification_results.csv` and `regression_results.csv`.

## 🔄 Using your own data

Replace `data/students.csv` with a real dataset (for example the UCI *Student Performance* dataset) and update:
1. the column names in `student_performance.py` (the target is `final_score`), and
2. `PASS_MARK` if your grading scale differs.
